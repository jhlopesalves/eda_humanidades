Curso de programação, análise de dados e estatística em Python voltado a estudantes e pesquisadores das humanidades.

Os materiais combinam fundamentos de Python, análise exploratória, visualização e raciocínio estatístico com exemplos baseados em textos, metadados bibliográficos e dados socioeconômicos.

**[Acessar o site do curso](https://jhlopesalves.github.io/eda_humanidades/)** · **[Começar pelo Encontro 1](https://jhlopesalves.github.io/eda_humanidades/encontro_1/enc_1.html)**

## Sobre o curso

O objetivo do curso é desenvolver autonomia para ler, modificar e produzir análises quantitativas em Python.

Programação e estatística são ensinadas em conjunto: o código não serve apenas para obter resultados, mas também para compreender como medidas, gráficos e procedimentos estatísticos são construídos, quais decisões entram em uma análise e como seus resultados devem ser interpretados.

Cada encontro pode ser lido diretamente no site e também aberto no Google Colab para execução e experimentação.
